Our application is a smart anti‑theft solution that uses motion detection and velocity tracking to identify suspicious activity when someone tries to steal your phone. It automatically enables location services, locks the device with face ID or PIN, and blocks unauthorized access until the rightful owner returns. The app also counts the number of swings or abnormal movements, giving you detailed insights into theft attempts. By combining sensor technology, biometric security, and cloud integration, it ensures your smartphone stays protected in real time.
